# مجموعه مستندات تست YAML Front Matter در Markdown RTL

این پوشه شامل سناریوهای جامع تست برای بررسی نحوه رندر و مدیریت **YAML Front Matter** در پیش‌نمایش مارک‌داون محیط‌های JetBrains (IntelliJ IDEA، Android Studio و ...) با استفاده از افزونه **Markdown RTL** است.

---

## سناریوهای تست (Test Cases)

| شماره | نام فایل | هدف از تست | آنچه باید بررسی شود |
| :---: | :--- | :--- | :--- |
| **01** | [`01-standard-persian.md`](./01-standard-persian.md) | فرانت‌متر استاندارد تمام‌فارسی | راست‌چین بودن متون مقادیر، اعمال فونت وزیرمتن، عدم تبدیل خطوط به تیتر H2 |
| **02** | [`02-bilingual-mixed.md`](./02-bilingual-mixed.md) | فرانت‌متر دوزبانه (ترکیب فارسی و انگلیسی) | تشخیص هوشمند جهت (BiDi) برای هر فیلد، چپ‌چین بودن فیلدهای انگلیسی و راست‌چین بودن فیلدهای فارسی |
| **03** | [`03-pure-english.md`](./03-pure-english.md) | فرانت‌متر تمام‌انگلیسی استاندارد | فونت انگلیسی مونو، چپ‌چین بودن کامل، استایل جدول مدرن |
| **04** | [`04-complex-yaml.md`](./04-complex-yaml.md) | ساختارهای پیچیده YAML | لیست‌های تو در تو (Nested)، مقادیر چندخطی (Multiline Folded `>`), انواع داده‌ها (بولین، اعداد، تاریخ) |

## چک‌لیست اعتبارسنجی در پیش‌نمایش

هنگام باز کردن هر کدام از فایل‌های بالا در تب Preview، موارد زیر را کنترل کنید:
- [ ] متادیتای ابتدای صفحه به صورت یک کارت متادیتای شکیل یا جدول مشخص نمایش داده شود.
- [ ] هیچ کدام از خطوط متادیتا به تیترهای بزرگ H2 اشتباهی تبدیل نشده باشند.
- [ ] متون فارسی در جدول متادیتا راست‌چین (RTL) و متون انگلیسی چپ‌چین (LTR) باشند.
- [ ] فایل `05-no-frontmatter-with-hr.md` باید همچنان یک خط افقی عادی رندر کند و کارت متادیتا نسازد.
- [ ] سرفصل‌های اصلی متن که بعد از فرانت‌متر قرار دارند، تمیز و بدون به هم ریختگی بعد از کارت متادیتا شروع شوند.
